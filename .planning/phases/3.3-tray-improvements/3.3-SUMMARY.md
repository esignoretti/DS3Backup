# Phase 3.3: Tray Icon & Menu Improvements — Summary

## Overview

Fixed the macOS tray icon startup bug and enhanced the system tray with status-aware icons, dynamic per-job menu, reliable notifications, and running-job indicators.

## Key Changes

### DISPLAY Gate Bug (CRITICAL)
- Removed `os.Getenv("DISPLAY")` check from tray startup in `daemon.go`
- `DISPLAY` is an X11 environment variable never set on standard macOS, completely preventing tray from appearing
- **File:** `internal/cli/daemon.go`

### Status-Aware Tray Icon
- Three icon states: idle (blue), running (green), error (red) — 16x16 solid PNGs
- `SetState(state TrayState)` method on `TrayApp` changes icon and tooltip
- Icon updates automatically via status refresh loop based on job states
- **File:** `internal/tray/tray.go`

### Dynamic Per-Job Menu
- Replaced one-shot `ensureJobBackupItems()` with `refreshJobMenuItems()` on every poll cycle
- Shows per-job status prefix: ✅ (completed), ❌ (failed), ⏳ (running), ▶ (no runs yet)
- Last run time shown in tooltip
- Handles jobs added/removed at runtime
- **File:** `internal/tray/menu.go`

### Reliable Notifications
- `sendMacOSNotification` tries `terminal-notifier` first, falls back to `osascript`
- `terminal-notifier` delivers reliably to Notification Center (brew-installable)
- **File:** `internal/tray/notifier.go`

### RunInProgress API Exposure
- Added `RunInProgress bool` to `BackupJobWithStatus` JSON output
- Tray menu reads this to show ⏳ for running jobs and update tray icon to green
- **File:** `internal/api/types.go`
