# Phase 3.3: Tray Icon & Menu Improvements

## Goal

Fix the macOS tray icon startup bug and enhance the system tray with status-aware icon, dynamic per-job menu showing last run result, reliable notifications, and running-job indicators.

## Success Criteria

1. Tray icon appears on macOS (fix `DISPLAY` gate bug — `DISPLAY` is X11-only, never set on macOS)
2. Tray icon changes color to indicate status: idle (blue), running (green), error (red)
3. Per-job menu items dynamically update to show last run result (✅/❌/⏳) and last run time
4. Notifications use `terminal-notifier` on macOS (brew-installable) with `osascript` fallback
5. Running backup jobs are indicated in the tray icon and menu
6. Jobs added/removed after tray start are reflected in the menu
7. All existing tests pass; `go build ./...` succeeds

## Implementation Plan

### Step 1: Fix DISPLAY Gate Bug

**File:** `internal/cli/daemon.go` (line 237)

Change condition from:
```go
if !daemonNoTray && !daemonNoAPI && runtime.GOOS == "darwin" && os.Getenv("DISPLAY") != ""
```
to:
```go
if !daemonNoTray && !daemonNoAPI && runtime.GOOS == "darwin"
```

`os.Getenv("DISPLAY")` is an X11 environment variable never set on standard macOS. This completely prevents the tray from ever appearing. The `else if` branch can also be simplified since there's no headless detection without DISPLAY.

### Step 2: Status-Aware Tray Icon

**File:** `internal/tray/tray.go`

Add icon data for multiple states (idle blue, running green, error red) and a method to switch icons:

```go
type TrayState int
const (
    StateIdle TrayState = iota
    StateRunning
    StateError
)

func (t *TrayApp) SetState(state TrayState) {
    switch state {
    case StateRunning:
        systray.SetIcon(runningIconData)
    case StateError:
        systray.SetIcon(errorIconData)
    default:
        systray.SetIcon(iconData)
    }
}
```

### Step 4: Reliable Notifications

**File:** `internal/tray/notifier.go`

Replace `sendMacOSNotification` to try `terminal-notifier` first, fall back to `osascript`:

```go
func sendMacOSNotification(title, message string) error {
    // Try terminal-notifier first (brew-installable)
    cmd := exec.Command("terminal-notifier",
        "-title", title,
        "-message", message,
        "-group", "com.ds3backup",
    )
    if err := cmd.Run(); err == nil {
        return nil
    }
    // Fallback to osascript
    script := fmt.Sprintf(`display notification "%s" with title "%s"`, message, title)
    return exec.Command("osascript", "-e", script).Run()
}
```
