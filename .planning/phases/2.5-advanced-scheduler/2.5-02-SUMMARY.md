# Phase 2.5 Plan 02: Scheduler Resilience Summary

**One-liner:** Added retry logic (3 attempts, 1-min intervals), per-job mutex overlap prevention, panic recovery with LastError recording, and scheduler checkpoint persistence with missed-schedule detection on restart.

## Objective

Make scheduled backups resilient to transient failures, prevent overlapping runs from corrupting state, and provide observability into missed schedules after daemon restarts. All features follow decisions D-01 through D-10.

## Key Changes

### Model Layer (`pkg/models/models.go`)
- Added `NextRetryTime` — when the next retry attempt is scheduled
- Added `RetryCount` — number of retries so far
- Added `RunInProgress` — runtime-only (json:"-"), NOT persisted
- Added `LastCheckpointTime` — per-job scheduler checkpoint for future granular tracking

### Retry Runner (`internal/scheduler/engine.go`)
- `BackupJobRunner` now holds `jobLocks map[string]*sync.Mutex` with `lockMu` for thread-safe lazy initialization
- `getJobLock(jobID)` helper lazily creates per-job mutexes
- `RunJob` rewritten:
  1. **Overlap prevention:** `lock.TryLock()` at entry — skips if another run is in progress, logs "Skipping scheduled run for job X"
  2. **Retry loop:** Up to 3 total attempts (initial + 2 retries), 1-minute intervals
  3. **Success path:** Clears `LastError`, resets `RetryCount`/`NextRetryTime`, saves config
  4. **Failure path:** Logs each attempt failure; after final exhaustion, sets `Job.LastError` and saves
- `RunJobAsync` enhanced: panic recovery now records panic details to `job.LastError` and saves config
- `retryInterval` field added (default 1 minute, configurable in tests)

### Scheduler Checkpoint (`internal/scheduler/scheduler.go`)
- `Scheduler` gains `checkpointTime` and `startTime` fields
- `Start()` logs missed schedule window on restart if `checkpointTime` is set and interval has elapsed
- `SetCheckpointTime` / `GetCheckpointTime` methods for integration with ScheduleManager

### ScheduleManager (`internal/scheduler/job.go`)
- `LoadAllSchedules` enhanced:
  1. Checks `Daemon.LastSchedulerCheckpoint` — if non-zero and >2 intervals ago, logs missed schedule warnings per job
  2. After loading, persists current time to `Daemon.LastSchedulerCheckpoint` and `Scheduler.checkpointTime`

### Config (`internal/config/config.go`)
- `DaemonConfig.LastSchedulerCheckpoint time.Time` — persisted checkpoint for missed-schedule detection
