<objective>
Convert the scheduler from single-cron-expression-per-job to multi-schedule-per-job. Jobs now support a list of cron expressions (`CronExprs []string`) instead of a single string. Each expression in the list fires the same backup pipeline. The API, scheduler engine, and model are updated consistently.

Purpose: Allow users to define multiple schedules per job (e.g., hourly incremental + daily full) by specifying multiple cron expressions. This is a foundational model change that subsequent resilience features build on.

Output: Updated BackupJob model (CronExprs replaces CronExpr), updated scheduler to schedule multiple expressions per job, updated API types/handlers and daemon adapter for the new format.
</objective>
