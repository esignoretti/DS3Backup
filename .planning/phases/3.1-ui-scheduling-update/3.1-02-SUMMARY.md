# Phase 3.1 Plan 02: Dashboard Multi-Schedule & Retry Display Summary

**Updated the dashboard SPA to display multiple cron expressions, @every interval labels, retry state, and support multi-expression editing**

## Key Changes

### `formatCron` → `formatCronExprs` (function replacement)
- Accepts `[]string` (cronExprs array) instead of single string
- Handles `@every <interval>` — displays "Every 6h" with blue styling
- Handles `@daily`, `@hourly`, `@weekly`, `@monthly`, `@yearly`, `@annually` descriptors
- Falls back to standard 5-field cron description for regular expressions
- Shows "Not scheduled" badge for empty/absent array

### `createJobCard` updates
- Schedule row: uses `job.cronExprs` array with `formatCronExprs()` (multiple lines via `<br>`)
- Retry info row: shown when `job.retryCount > 0`, displays attempt number and next retry time
- Reschedule button: passes `cronExprs` array (via `JSON.stringify`) instead of single `cronExpr` string

### `rescheduleJob` updates
- Accepts array of current expressions (joined as comma-separated prompt default)
- Parses user's comma-separated input into `cronExprs` array
- Sends `cronExprs:exprs` in PATCH body (not deprecated `cronExpr`)
- Shows error details from API response on failure

### Add-job modal updates
- Schedule input placeholder updated to show multi-expression examples
- Hint text added explaining comma separation and @every support
- `createJob` sends `cronExprs:crParsed` array (parsed from comma-separated input) instead of single `cronExpr`
